# LingoForge CAT 产品路线图

## 产品定位

面向游戏发行与本地化人员的本地优先 CAT 桌面软件。第一阶段聚焦单人工作，不建设账号、权限、任务分配和多人实时协作。

## 第一阶段：可用的翻译工作台

- 项目创建与本地项目库
- [进行中] Excel、CSV、JSON 文件导入（已支持 XLSX、CSV、TSV；JSON 待开发）
- [已完成] 原文/译文句段编辑器
- [进行中] 原格式或指定格式导出（已支持 XLSX、CSV、TSV 原行列回写）
- [已完成] 自动保存与项目恢复
- [进行中] 搜索、筛选、批量选择和快捷键
- [进行中] 数字、占位符、标签和换行符保护

## 第二阶段：翻译资产

- [进行中] 翻译记忆库导入、导出和模糊匹配（已支持 XLSX、CSV、TSV 导入与实时匹配）
- [进行中] 术语库导入、导出、命中提示和强制检查（已支持 XLSX、CSV、TSV 导入与实时命中）
- [已完成] 资产本地持久化、移除和语言对隔离
- 多游戏、多语种资产隔离与共享
- 重复句段自动填充
- 资产来源、修改时间和使用次数记录

## 第三阶段：AI 翻译

- OpenAI 兼容接口
- Anthropic、Gemini 等供应商适配
- 项目级提示词和翻译风格
- 角色、场景、文本类型和上下文注入
- 分批翻译、一致性约束和失败重试
- API 消耗统计与模型对比测试

## 第四阶段：质量保证

- 非译元素和标签完整性检查
- 数字、标点、空格、换行和漏译检查
- 术语一致性和同源多译检查
- 长度限制和敏感词检查
- QA 报告与问题定位

## 第五阶段：内部验证与技术交接

- Windows 安装包
- 真实项目压力测试
- 越南语、泰语、韩语等语种测评
- 用户操作手册
- 产品需求、架构、数据库和接口文档
- 源代码与技术部门交接
