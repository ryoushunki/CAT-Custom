# LingoForge CAT

面向游戏本地化的本地优先桌面 CAT 工具。

## 本地开发

```powershell
npm.cmd install
npm.cmd run dev
```

## 构建

```powershell
npm.cmd run build
```

## 当前能力

- 现代化三栏翻译工作区
- 原文/译文双栏句段编辑
- 翻译状态、进度和匹配率展示
- 原文与译文搜索
- 未翻译、待检查、已翻译筛选
- 译文自动保存
- 翻译记忆和术语建议面板原型

当前版本为第一阶段可运行骨架，示例数据暂存于本机浏览器存储。下一阶段将接入本地数据库、Excel 文件解析、术语库、翻译记忆库、标签保护、QA 和 AI 翻译。
