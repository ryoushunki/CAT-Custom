# LingoForge CAT

面向游戏本地化的本地优先桌面 CAT 工具。

## 本地开发

```powershell
npm.cmd install
npm.cmd run dev
```

## 构建

```powershell
npm.cmd run build
```

## 当前能力

- 现代化三栏翻译工作区
- 原文/译文双栏句段编辑
- 翻译状态、进度和匹配率展示
- 原文与译文搜索
- 未翻译、待检查、已翻译筛选
- 译文自动保存
- 三个示例文件可真实切换并分别保存
- XLSX、CSV、TSV 两列文件导入
- 句段状态点击切换
- 翻译建议一键采用
- 建议、AI、术语面板页签切换
- 未实现功能明确禁用并显示说明
- 自定义标题栏窗口拖动
- 翻译记忆和术语建议面板原型

当前版本使用 IndexedDB 保存项目文件和句段，数据仅保存在本机。当前导入规则为 A 列原文、B 列译文；下一阶段将补充原格式导出、项目管理、正式术语库、翻译记忆库、标签保护、QA 和 AI 翻译。
